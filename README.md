# 🚀 Aura 灵犀招聘系统 (Aura-ATS)

Aura 是一款基于大语言模型 (LLM) 驱动的现代化智能招聘管理系统 (ATS)。其界面融合了现代、简洁的 **Apple 设计哲学**（如毛玻璃拟态、Bento Grid 磁贴布局和微交互动效），提供卓越的 SaaS 级 UI/UX 体验。

---

## 🛠️ 技术栈与架构
*   **后端**：`Python (FastAPI)` + `SQLAlchemy (ORM)` + `SQLite / MySQL`
*   **AI 简历解析**：`Google Gemini API` (具备轻量模型自适应轮询与脱机演示降级兜底功能) + `pdfplumber`
*   **安全与鉴权**：
    *   **JWT 身份令牌**：采用 `pyjwt` 生成与校验 Token，用于全站 API 越权拦截与权限隔离。
    *   **密码哈希安全存储**：采用 Python 内置标准库 `PBKDF2-HMAC-SHA256` 进行强哈希存储，确保数据安全并免去 C 语言库编译依赖。
*   **前端**：原生 `HTML` + `Vanilla CSS` + `JavaScript` (零框架、极速轻量)

## 📦 快速本地启动

### 1. 克隆/打开项目并安装依赖
我们新增了 `pyjwt` 依赖。请在终端执行以下命令进行依赖更新安装：
```bash
# 激活您的虚拟环境 (如果有的话，例如 venv)
source venv/bin/activate

# 安装最新依赖
pip install -r requirements.txt
```

### 2. 配置环境变量
在项目根目录下创建 `.env` 文件，并配置您的 Gemini API 凭证：
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. 运行本地开发服务器
启动 FastAPI 异步服务器：
```bash
python main.py
```
默认服务将运行在 `http://localhost:8000`。

## 👥 协同成员邮件邀约与入伙工作流
系统支持管理员邀请新成员共同管理招聘流程：
1. **发起邀请**：超级管理员可在“系统设置 -> 成员邀请”页面中输入被邀请人的“邮箱”、“姓名”、“部门”并配置“角色权限”（系统管理员/HRBP/用人经理/面试官）。
2. **激活链接**：系统生成唯一的 `invite_token` 激活链接（目前在开发/演示阶段以 Mock 形式将邀请邮件正文打印至服务器日志中）。
3. **注册激活**：被邀请人访问该专属链接，系统将自动锁定邮箱、部门与角色等核心信息，仅需设定密码并确认姓名即可一键激活并自动登录。
4. **权限隔离**：不同的角色（如面试官）登录后将根据其身份自动隔离展示相关的数据。

## 🌐 求职者外网自主投递工作流 (Public Apply Portal)
系统为每个职位提供公共投递入口，允许外部求职者免登录自助投递：
1. **外网投递链接**：格式为 `http://localhost:8000/portal.html?job_id={job_id}`，可在未登录状态下直接访问。
2. **免鉴权公开投递**：投递表单调用免鉴权公开 API 端点 `/api/public/submit-resume`，支持直接上传 PDF 简历。
3. **AI 自动解析与入库**：求职者投递后，后台通过 Gemini 对简历进行深度解析与评分，自动将候选人归入“初筛”阶段，并在系统管理员/HRBP 工作台的“最近动态”中推送提醒，实现投递到初筛的完整自动化闭环。

## 💼 职位管理与全字段在线编辑 (Job Management & Editing)
系统支持 HR/管理员对招聘职位进行全生命周期管理与在线修改：
1. **职位发布与编辑**：在职位卡片操作区点击“编辑”按钮（`add-job.html?job_id={id}&mode=edit`），自动回填 13 项核心字段并支持无感修改与保存。
2. **JD 质量强校验与清洗**：支持一键套用标准规范 JD 模板，内置 HTML 富文本清洗与纯文本不少于 100 字强校验，避免脏数据流入。
3. **实时全渠道同步**：职位信息更新后，公开求职投递页 (`/portal.html?job_id={id}`) 零缓存即刻同步展示最新岗位要求与薪酬待遇。

## 🎯 候选人全生命周期流程管理 (Candidate Lifecycle Pipeline)
系统提供标准化的 6 大核心流程流转与状态机防重闭环：
1. **核心流程链条**：`初筛` ➔ `部门筛选` ➔ `面试` ➔ `Offer` ➔ `背调` ➔ `入职`（以及分支终态 `已淘汰`、`已归档`）。
2. **全操作审计留痕**：支持**推进**、**撤回**（回退上一节点）、**驳回淘汰**与**重新进入流程**。每次状态变更强制持久化记录操作人姓名、精确时间戳及流转原因备注，并实时渲染于候选人详情页时间轴中。
3. **流程防重机制**：
   - **投递/录入拦截**：同一候选人若已在当前职位的活跃招聘流程中，系统自动拦截重复投递或录入，防止脏数据产生；
   - **状态机合规校验**：已淘汰/归档候选人禁止直接推进，需通过“重新进入流程”重新激活重置回初筛节点；禁止同节点重复推进。

## 🔔 统一操作反馈与高风险操作二次确认 (Operation Feedback & Risk Confirmation)
系统遵循现代严谨的 B 端交互规范，提供全状态操作反馈与高风险防手抖保护：
1. **统一 5 态反馈闭环**：全系统操作均具备**成功 (Success)**、**失败/异常 (Error)**、**加载中 (Loading)**、**无权限 (Forbidden)**、**数据为空 (Empty State)** 完整支持。
2. **状态联动优先，Toast 仅作辅助**：
   - 关键操作（流转、推荐、停招、入职确认）成功后即时触发 DOM 树原地更新与数据重新计算，告别“只弹 Toast 页面无响应”的伪完成；
   - 提交期间异步按钮自动注入微型 Spinner 动画并禁用防重。
3. **企业级高风险操作二次确认 (`showDangerConfirm`)**：
   - 全面取缔原生简陋 `confirm`，在**淘汰候选人**、**批量流转/淘汰**、**职位停止招募**、**正式入职确认**等场景中弹出带有警告图标、被操作对象高亮及不可逆风险说明的高保真二次确认弹窗。
