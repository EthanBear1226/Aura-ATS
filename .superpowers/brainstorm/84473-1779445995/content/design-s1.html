工作台 2.0 详细设计 (Section 1/3)

我们将先确定整体架构与布局逻辑，确保其符合 Apple 的设计美学。

架构与布局方案

1. 技术架构 (Backend-Driven)

我们将新增 /api/workbench/dashboard 接口，根据登录态返回聚合数据：

{
  "stats": { "active_jobs": 5, "pending_candidates": 12, "interviews_today": 3 },
  "todos": [ { "type": "interview", "title": "初试：刘晨", "time": "14:00" }, ... ],
  "activity_stream": [ { "content": "张三 提交了评价", "time": "10分钟前" }, ... ]
}

2. 布局逻辑 (Responsive Grid)

采用 Bento Box (便当盒) 布局。在大屏下为三栏/两栏异步排布，在移动端自动堆叠。每个组件（Widget）都是一个独立的卡片。

主待办区
动态流
快捷数据统计
