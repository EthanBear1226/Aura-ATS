# 职位发布页 UI 重构与视觉升级设计文档

## 1. 目标与背景
当前的职位发布页面 (`add-job.html`) 存在原生系统控件痕迹过重的问题，并且由于内联 CSS 和底部 JavaScript 的冲突，导致部分下拉框出现了“双箭头”的视觉 Bug。
为了使整个 Aura 系统的 UI/UX 符合现代 SaaS 和 Apple 风格的极简美学，决定对该页面进行重新设计。

## 2. 核心架构与布局
保留目前的双列网格 (`form-grid`) 布局和富文本编辑器，重构重点在表单控件组件。

### 2.1 Bug 修复：清除双箭头
- **原因**：顶部的内联 CSS 为 `.form-group select` 添加了 `background-image`（原生箭头），而底部的自定义 Select 逻辑也生成了额外的箭头 DOM。
- **方案**：移除 `<style>` 中针对 `.form-group select` 的原生箭头背景相关的 CSS，完全由底部的自定义组件逻辑接管样式。

### 2.2 胶囊分段控制器 (Segmented Controls)
对于选项固定且数量较少的字段，采用 iOS 风格的横向胶囊按钮进行展示：
- **涉及字段**：
  - 职位类别 (技术/产品/运营/职能)
  - 职位性质 (全职/兼职/实习/外包)
  - 职级 (初级/中级/高级/资深)
  - 工作经验 (不限/应届/1-3年/3-5年/5-10年)
- **交互逻辑**：隐藏原生 `<input type="hidden">` 用于存储数据，通过 JavaScript 渲染 `.segmented-control`。点击胶囊时，切换高亮状态 `.active` 并更新隐藏域的值。

### 2.3 极简下拉框保留与优化
对于选项较多或可能动态变化的字段，保留自定义美化后的下拉框：
- **涉及字段**：所属部门、工作地点、负责人、面试流程。
- **优化**：修复边框、焦点颜色和必填错误的高亮（`.has-error`）展示，确保与其他输入框的一致性。

## 3. 数据流与验证
- 表单提交前，验证逻辑会检查隐藏输入框（对于胶囊控件）和原生 Select/Input 的值。
- 对于未填写的必填项，对应的胶囊组外部容器或下拉框触发区域将增加红色高亮类 `.has-error`。

## 4. 实施边界 (Scope)
- **仅修改 `add-job.html`**，不涉及后端 API 修改。
- 不引入外部组件库（除了已有的 Quill.js），完全使用 Vanilla JS + CSS 实现交互。
